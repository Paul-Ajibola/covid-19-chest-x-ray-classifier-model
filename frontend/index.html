01 What the model does

DenseNet-121

One image. Four possible classes.

Thorax uses DenseNet-121, a convolutional neural network, to look for visual patterns in a chest X-ray. It assigns a probability to each of four classes and displays the highest-scoring class as its prediction.

03 Understand the output

Predicted class = the highest score

The class with the highest probability is displayed as the prediction. It is a model label, not confirmation of health.

Confidence = the selected class’s score

The confidence score is the probability assigned to the predicted class. It does not mean the prediction is correct.

Read the whole distribution

The four scores total 100%. They show how the model distributes its output across these classes, not four separate diagnoses. Close scores show a less clear preference.

04 Keep the limits in mind

It can make mistakes

Visual patterns can be ambiguous. Image quality and differences between images can affect the output. A confident result may still be incorrect.

Four classes are not the full picture

The model only scores these four categories. Other findings and conditions are outside this output; a low score does not rule them out.

It does not assess a person

An image alone does not provide symptoms, history or clinical context. This demonstration cannot replace a qualified healthcare professional.

iDo not base medical decisions on these outputs. For health concerns, seek advice from a qualified healthcare professional.
